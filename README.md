# IAPWS-IF97 Calculator

Высокопроизводительная реализация международного стандарта **IAPWS-IF97** для расчета теплофизических свойств воды и водяного пара на языке Rust.

Проект представляет собой монорепозиторий, включающий оптимизированное математическое ядро и два варианта графического интерфейса (нативный и веб/Tauri).

## 📂 Структура проекта

Проект разделен на три основных компонента:

* **`core/`** — Математическое ядро библиотеки.
    * Реализует прямые и обратные расчеты для всех регионов (1–5), включая околокритическую зону и метастабильный пар.
    * Использует `build.rs` для кодогенерации таблиц коэффициентов из CSV на этапе компиляции (zero-cost абстракция).
    * Предоставляет строгую типизацию величин (МПа, К, кДж/кг) для защиты от ошибок.
* **`fltk/`** — Нативный десктопный интерфейс.
    * Написан на базе библиотеки FLTK.
    * Легковесный, быстрый, собирается в единый бинарный файл.
    * Включает построение графиков (через `plotters`), одиночные и табличные (batch) расчеты.
* **`wasm/`** — Современный кроссплатформенный интерфейс (Tauri + WebAssembly).
    * Позволяет запускать приложение как десктопную программу с красивым веб-интерфейсом.
    * Поддерживает экспорт таблиц, графиков и сохранение логов.

## ✨ Основные возможности

* **Полное соответствие стандарту:** Поддержка всех 5 регионов IAPWS-IF97.
* **Различные типы расчетов:** * Прямые: $p, T \rightarrow v, h, s, c_p, w$
    * Обратные: $p, h$, $p, s$ (через встроенные итерационные решатели).
    * Влажный пар: $p, x$.
    * Околокритическая зона: $\rho, T$.
* **Пакетная обработка:** Загрузка `.csv`/`.txt` файлов, расчет сотен точек и экспорт результатов.
* **Визуализация:** Построение T-s, h-s и других диаграмм прямо в приложении.

## 🚀 Как запустить

Убедитесь, что у вас установлен [Rust](https://rustup.rs/).

### Запуск тестов ядра
Проверка математических моделей на соответствие контрольным точкам стандарта:
```bash
cd core
cargo test
```
### Запуск нативного десктоп-приложения (FLTK)
``` bash
cd fltk
cargo run --release
```

### Запуск Tauri/WASM приложения
Требуется установленный Tauri CLI.

``` bash
cd wasm
cargo tauri dev
```

## 🛠 Автоматизация (CI/CD)
Проект настроен на использование GitHub Actions (.github/workflows/release.yml). При пуше новых тегов (например, v0.1.0) автоматически запускается проверка кода и сборка релизных бинарников.
