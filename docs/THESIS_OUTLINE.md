# Заготовка для дипломного описания проекта

Этот файл предназначен как “пакет подсказок” для автора текста (агента), который будет описывать результаты разработки в дипломной работе.

## 1. Возможное название темы

Варианты формулировок:

- «Разработка кроссплатформенного программного комплекса для расчета теплофизических свойств воды и водяного пара по стандарту IAPWS-IF97 на языке Rust».
- «Проектирование и реализация вычислительного ядра и средств доставки (desktop/web/gRPC) для инженерных расчетов по IAPWS-IF97».

## 2. Цель и задачи (пример)

Цель: реализовать программный комплекс, который выполняет расчеты по IAPWS-IF97 и предоставляет удобные способы использования для инженера и для интеграции в инфраструктуру.

Задачи:

- реализовать вычислительное ядро IF97 с безопасным API и единицами измерения;
- поддержать прямые и обратные расчеты (p-T, p-h, p-s, p-x, rho-T) и метастабильную область;
- сделать 2 пользовательских интерфейса (нативный FLTK и web/Tauri) с табличным расчетом, графиками и экспортом;
- реализовать gRPC-сервис для пакетных расчетов с высокой пропускной способностью;
- обеспечить воспроизводимую сборку, тестирование и публикацию артефактов через CI/CD;
- подготовить документацию (rustdoc и проектные `.md`-материалы).

## 3. Объект/предмет и входные данные

Объект: термодинамические свойства воды и водяного пара, рассчитываемые по IAPWS-IF97.

Типовые входы:

- давление `p` (МПа)
- температура `T` (K)
- энтальпия `h` (кДж/кг)
- энтропия `s` (кДж/(кг*К))
- плотность `rho` (кг/м³)
- степень сухости `x` (0..1)

Типовые выходы:

- `v`, `rho`, `h`, `s`, `u`, `cp`, `w` + классификация региона IF97.

## 4. Архитектурное решение (что подчеркнуть)

Ключевые идеи:

- монорепозиторий + Rust workspace;
- одно ядро `if97_core`, все остальные компоненты тонко адаптируют его;
- явный слой DTO `if97_app_api` для стабильного обмена данными между UI и backend;
- различение I/O и CPU для сервиса (tokio vs rayon), backpressure и лимиты in-flight;
- детерминированная сборка коэффициентов через build-time codegen из CSV.

## 5. Описание компонентов (что писать)

### 5.1. `if97_core`

Что описать:

- регионы IF97 (1–5), линия насыщения (Region 4), граница B23;
- прямые и обратные расчеты и их маршрутизация через engine;
- типобезопасные единицы измерения (newtype’ы);
- обработка ошибок и валидация диапазонов;
- генерация таблиц коэффициентов из CSV в `build.rs` (почему так сделано).

### 5.2. FLTK UI

Что описать:

- режимы ввода, одиночный и табличный расчет;
- сохранение наборов данных (точки/таблицы) и построение диаграмм;
- купол насыщения, автоскейлинг, экспорт (логов/графиков/таблиц).

### 5.3. Web (Yew/WASM) + Tauri

Что описать:

- web-frontend на Yew, сборка через Trunk;
- Tauri-backend: команды `calculate_single/calculate_table/calculate_dome`, файловые диалоги, логирование;
- почему тяжелые расчеты выполняются в blocking-пуле (чтобы не блокировать runtime).

### 5.4. gRPC service

Что описать:

- bidirectional streaming;
- формат SoA (p[]/t[] -> h[]/status[]);
- backpressure (per-connection и global in-flight);
- разделение пулов tokio/rayon, почему это важно для throughput;
- health-check и корректное завершение (drain).

### 5.5. CI/CD

Что описать:

- workflow’ы GitHub Actions: docs (Pages) и release (matrix, артефакты);
- семантическое версионирование и релизы по тегам `vMAJOR.MINOR.PATCH`;
- какие артефакты публикуются (Tauri bundles, FLTK, rustdoc, web dist).

## 7. Результаты разработки (готовый список)

В результате реализовано:

- вычислительное ядро IAPWS-IF97 (`if97_core`) с типобезопасными единицами и набором прямых/обратных расчетов;
- общий слой DTO (`if97_app_api`) для стабильного обмена между компонентами;
- нативный desktop-клиент на FLTK с табличным расчетом, диаграммами и экспортом;
- web/WASM интерфейс на Yew и desktop-упаковка через Tauri, включая системные функции (файловые диалоги, экспорт);
- gRPC-микросервис с streaming API, backpressure и CPU-пулом для батчевых вычислений;
- Docker-образ и Kubernetes-манифесты;
- автоматизированные сборки и публикации через GitHub Actions (релизы и документация).
