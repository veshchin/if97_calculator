# Документация проекта `if97_calculator`

Этот каталог содержит человекочитаемую документацию по проекту (не API reference).

Если вам нужно описание для диплома или для передачи третьей стороне (например, другому агенту/автору),
начинайте с:

- [`PROJECT.md`](PROJECT.md) — единый документ по проекту: цель, архитектура, компоненты, сборка, релизы.
- [`THESIS_OUTLINE.md`](THESIS_OUTLINE.md) — заготовка структуры текста диплома и список результатов.

API reference (детальная документация по публичным типам/функциям) генерируется через `rustdoc`:

```bash
cargo doc -p if97_core -p if97_app_api -p if97_calculator_service --no-deps --open
```
