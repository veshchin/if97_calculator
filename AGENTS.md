# Инструкции для агентов

Данный файл содержит инструкции для агентов, применяемые в любом контексте.

## Действия, выполняемые только после одобрения пользователя или если обратное указано прямо в последнем сообщении

- Любые взаимодействия с git
- Любые установки стороннего ПО
- Любое изменение файлов

## Инструкции к каждому из промтов

- После получения сообщения ты составляешь краткий план выполняемых действий
- Перед тем, как закончить работу, ты составляешь краткое саммери выполненных действий
  - Если что-то выполнить не получилось ты прямо об этом пишешь и приводишь рекомендации к тому, как это можно было бы исправить
